Ghana Ride-Hailing Competitor Analysis Dashboard
An Excel dashboard project analyzing the performance of leading ride-hailing companies in Ghana in 2025.

Project Overview
This project uses Microsoft Excel to examine and compare the performance of four ride-hailing companies: Bolt, Shaxi, Uber, and Yango.

Using the same dataset, I developed two dashboard versions to explore the data from different perspectives and present key performance indicators in a visual format.

Key Performance Indicators
Total Revenue

Total Bookings

Active Drivers

Dashboard Features
Comparison of market leaders by revenue

Comparison of market leaders by bookings

Revenue and bookings by month

Interactive filters for months and ride-hailing companies
